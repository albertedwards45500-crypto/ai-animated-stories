# 角色形象与分镜一致性

## 使用流程

1. 在项目角色库填写角色的外观信息与画风，点击“AI 生成形象”。模拟模式返回本地测试图，真实模式使用配置的图片 Provider，提交前会提示可能产生费用。
2. 对比候选图，选定一张主参考图，点击“确认并锁定”。锁定后不可再修改角色卡与主参考图。
3. 在剧集分镜中选择出场角色，先生成关键帧，再由该关键帧生成视频。真实图片任务会带入所有出场角色的主参考图；真实视频任务沿用关键帧首帧。
4. 任务会记录角色 ID、版本、主参考图素材 ID；角色信息或分镜出场人物变化后，旧关键帧不能继续用于真实视频生成。

## 边界

- 当前真实图片 Provider 是 DashScope qwen-image-3.0，多张主参考图作为图像编辑输入，单镜头最多 3 张；模型有概率改变五官、服装或人物身份，无法在纯提示词层面保证绝对一致。
- 当前真实视频 Provider 是 DashScope wan3.0-video，使用关键帧作为输入首帧，运动提示词要求保留脸部、发型和服装。仍建议逐镜人工复核，必要时重新生成关键帧。
- 模拟模式只验证任务、引用和素材绑定，不评估模型的视觉一致性。测试图来自本地素材目录，未调用外部 AI API。
- 角色库先上传或生成主参考图，再锁定。已锁定角色要换形象时，需要新增角色版本的解锁/复制流程；本版不直接覆盖锁定素材。
- 真实图片和视频服务只在非模拟环境且配置了对应 Provider 时调用；本次仅通过 Mock Provider 与离线假响应验证请求结构，未调用真实 AI API。
